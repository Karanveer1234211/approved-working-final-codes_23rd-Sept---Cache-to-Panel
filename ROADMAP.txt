WHAT IS GUARANTEED AT THIS STAGE
  - No fabricated bars. Missing stays missing; NaN propagates honestly.
  - Orphan bars trimmed (Kite reuses tickers after delisting).
  - Labels joined on timestamp, never on positional index.
  - Label columns cannot enter X - use panel_feature_columns().
  - The last 5 sessions are UNKNOWN, not negative.
  - Liquidity floor is point-in-time: a name enters and leaves as its
    turnover changes. Not hindsight.
  - Build signature covers universe + floor + labels + cross-sectional set.
    Changing any of them FORCES a full rebuild rather than silently mixing.
  - CACHE_DAILY_ROOT unset is now a hard error (v29). There is no default.

FROZEN PARAMETERS - changing any of these invalidates the panel
    CACHE_HISTORY_ANCHOR = 2015-01-01    NEVER CHANGE (expanding-rank alphas)
    LABEL_HORIZON        = 5 sessions
    PRIMARY_VARIANT      = atr1p5_1p0
    liquidity floor      = 1e7 (Rs 1 crore/day, 60-session median)
    embargo              = 5 sessions

LABEL VARIANTS IN THE PANEL (all computed, one is primary)
    5p3          fixed 5% TP / 3% SL
    3p2          fixed 3% / 2%
    atr1p5_1p0   1.5 x ATR / 1.0 x ATR   <-- PRIMARY

    atr1p0_1p0   1.0 / 1.0
